# Mapa de telas

| Entrada | Estados e destinos |
| --- | --- |
| Sessão | Verificação → entrar com Google → consulta de UID |
| Acesso | Solicitar → em análise → painel ou rejeição. Suspensão e revogação retornam à área restrita |
| Painel | KPIs, assunto, filas, vínculos e atividade → listas filtradas e detalhes |
| Pendências | Busca e filtros combináveis → ID → próxima ação, contexto, fontes e histórico |
| Detalhe | Editar, arquivar ou restaurar → revisar diff → gravar |
| Atualizar | Texto ou ditado → prévia → editar, aceitar ou rejeitar cartões → confirmação → resultado por item |
| Atividade | Busca e autor → expandir antes/depois ou abrir ID |
| Mais | Acessos, exportação, ajuda, instalação e logout |
| Acessos | Solicitações, membros, perfil, suspensão e revogação |
| Exportação | Snapshot JSON/CSV e resumo semanal copiável |
| Estados de falha | Rede, login, conflito, índice em criação e IA indisponível |

Referências de composição: mobile 390×844, tablet 768×1024, desktop 1440×900. A interface admite largura de 360 px.
